# Defeatist ミュージックプレーヤー *for M5Tab5*

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語** · [Español](README.es.md)

たいていの M5Tab5 用メディアプレーヤーは、まずファイルを*変換*しろと言ってくる。これは違う。

このプロジェクトの目標は、ハードウェアに手を加えずにこの端末の潜在能力を限界まで引き出すこと。はんだ付けなし、あとで取り外せないアクセサリもなし。ESP32-P4 v1.3 が裏技なしで無理なく扱えるフォーマットは、すべて対象。

> これは機械翻訳です。正典は英語版 [README.md](README.md)。画面上の短いラベルは [ABBREVIATIONS.ja.md](ABBREVIATIONS.ja.md) を参照。

## M5Stack Tab5 は理想的な音楽プレーヤーではない。

- Bluetooth があると思っているだろう。
  - あるのは低消費電力 Bluetooth（BLE）だけ。つまりクラシック Bluetooth の古い機器からは永遠に見えない。
  - LE Audio / Auracast には別の配線とプロファイルが要る。C6 を焼き直せば動くかもしれないが、それには[専用機材](https://docs.m5stack.com/en/guide/restore_factory/m5tab5_c6_wifi)が必要。
- ヘッドセット端子がある。
  - ヘッドセットには最適。AUX ケーブルにも。理論上は録音にも。
  - だがインラインのボタンを拾うものは何もない。配線すればできるらしいが、これもまた（そこまで特殊ではない）専用機材が要る。
- ディスプレイとタッチは同じチップが制御している。バックライトは消して節電できるが、ディスプレイを完全に切ることはできない。
- そしてディスプレイドライバの混沌。
  - 初回リリース（2025.5.9）：独立した ILI9881C ディスプレイドライバ + GT911 タッチコントローラ
  - 2025.10.14：ST7123 ディスプレイ・タッチ一体（TDDI）ドライバに変更
  - 2026.4.28：ドライバ IC が ST7123 から ST7121 に変更（手元に届いたのはこれ）

## 3 つのシナリオ

1. ストレージはないが Wi-Fi（またはイーサネットドングル）はある：インターネットラジオを聴ける。
2. ストレージはあるが音楽がない：あとで再生するために FLAC を録音できる。
3. ストレージも音楽もある：これがあなたの音楽プレーヤー。ヘッドホンあり・なし、USB オーディオクラス（UAC）ドングル対応。

## ESP-IDF ~~5.5.5~~ 6.1 で動かせたもの

- microSD カードと USB メモリのホットプラグ
  - microSD カードが優先。消費電力が少ない。
  - ただし USB インジケータが緑なら USB も自動マウントする。緑でなければ設定で USB 給電をオンに戻す。
- exFAT 対応
  - SDHC と SDXC はテスト済み（後者は 1 週間で死んだが、ソフトのせいではない）。SDUC は未テスト。ブルーレイ級の大きさの音声ファイルは再生できる？さあね。
- 抜き差しでヘッドセットと内蔵スピーカーを自動切替
  - 音量スライダー横のアイコンが、実際に鳴っている出力を示す——スピーカー、ヘッドホン、または USB オーディオ機器が出力を握っているときは `UAC`。タップでミュート／解除。
- （把握している限り）あらゆる MP3 フォーマット変種に対応。このプレーヤーはフォールバックライブラリの上にフォールバックライブラリを重ねている。Flac、ogg、wav といった定番も入っている。
- アルバムアート表示：ファイルに埋め込まれた画像でも、隣に置かれた cover.jpg / folder.jpg / front.jpg でも。
- バッテリー状態を、ステータス行の末尾に文字で表示：`BATT 73%`、`CHRG 73%`、`CHARGED`、`NO BATT`。
- ステータス行の Wi-Fi：緑は接続済み、黄は接続中、グレーはオフ。
- 音量調整
- 再生／一時停止
- 曲の先頭へ／前の曲（ダブルタップ）
- 次の曲
- 画面スリープ
- ドラッグでシーク。上記のどのフォーマットでも。
- 再生順ボタンは ONE / ALL / RPT / EAT / RND / RPT1 を循環——各々の意味と、画面上の他のすべての短いラベルは [ABBREVIATIONS.ja.md](ABBREVIATIONS.ja.md) に。
- シークバー上の音量波形。かっこいいと思って。
- USB オーディオクラス（UAC）対応——「PS5 に Bluetooth ヘッドホンを足す」あのドングルもここで使える。USB-A ポートのみ。
- 一時停止でアンプの電源を切る。
- SDRAM キャッシュ。曲の切り替わりの 20 秒ほど前に挙動がおかしくなったら、issue を立ててほしい。
- ReplayGain 対応。曲を最後まで初めて聴くとき、Defeatist も一緒に聴く——以後の再生では、小さい曲は上げ、大きい曲は下げる（常識の範囲で）。根拠は [BS.1770](https://www.itu.int/rec/R-REC-BS.1770/en)。
  - シークバーの波形は同じ聴取から得られる。曲を最後まで一度聴き終えるまでは、波形は無地のグレー。
  - この初回聴取中にスキップやシークをするとキャンセルされる——次回また試みる。
  - このメタデータは隠しファイル `.songname.rgcache` に入る。計算は止められないが、音量調整は設定でオフにできる。
- ARK 12 は Unicode の相当部分をカバーするが、完全ではない。
- 起動時に前回再生した曲を開き直す。自動再生ではない。
- メディアを抜いたとき 3 秒フェード。
- 設定可能なクロスフェード。
- ギャップレス再生データをちゃんと見ている。
- <https://www.radio-browser.info> API、または手動リスト入力によるインターネットラジオ。これは「電源につなぐ」領域。
  - MP3・AAC・Ogg ストリーム、および平文または MPEG-TS セグメントで AAC か MP3 を含む HLS（`.m3u8`）に対応。未対応：暗号化または fMP4 の HLS、および放送局が配る `.pls`/`.m3u` リンク。
- アラビア語のタイトルと局名を、右から左へ連結して右端揃えで配置。
- スリープタイマー（最長 2 時間、15 分刻み）。
- アイドル自動電源オフ：再生・録音・操作のいずれもない状態が 15 分〜2 時間続くと電源を切る——スリープタイマーとは別物。カウントダウン中はステータス行の `IDLE` が緑、何かが電源オフを押しとどめているときは黄。サイドボタンで復帰。
- 低バッテリー保護：バッテリー電圧が 6.3 V を 30 秒下回ると、進行中の録音を終えて自ら電源を切る。パックを傷めるほど放電しきる前に。実際の放電では未検証。
- 明るさ調整。
- Network Time Protocol（Wi-Fi 設定済みのとき）。
- バッテリーバックアップ時計が電源オフをまたいで時刻を保持するので、Wi-Fi がなくても録音ファイルに正しい名前が付く。可能なときは NTP が補正する。
- キャプティブポータル方式の Wi-Fi 設定（複数ルーター対応）。
- Wi-Fi ポータルのウェブ画面からインターネットラジオ局を手動入力。
- お気に入り（Starred Favorites）。
- USB イーサネットドングル：CDC-ECM（Realtek RTL8152 テスト済み。RTL8153 は同じ経路、未テスト）と [ASIX AX88772](https://github.com/Sudrien/esp_usbh_asix) 移植。いずれも実機で確認済み。
- Cue シート。
- m3u/m3u8——少なくとも MPD 経由で。
- そうだ、[Music Player Daemon](https://mpd.readthedocs.io/en/stable/user.html) 対応——つまり Home Assistant からの制御もできるはず。
- HTTPS のウェブ UI。
- 音声録音。ハードがそこにあるので、FLAC で。
  - 録音中はレベルメーター付き。
- 音量の下の 1 行のステータス：USB 給電、MPD、HTTPS、そしてスリープタイマーの残り分。緑がオン。
- ああ、M5Launcher のアプリ一覧を見てしまった。今すぐタイトルの並びを直そう。
- 画面の言語（English、简体中文、日本語、Español）、設定の歯車 >> BUILD タブで選択。
- [bmorcelli/Launcher](https://github.com/bmorcelli/Launcher) 対応
  - Launcher へ戻る
  - Wi-Fi 認証情報のインポート

## 現在公開中のコードでは実現しないこと

- クラシック Bluetooth ドングル対応。
- ファイル単位のレジューム。
- USB ハブ。
  - 挿したことは分かる？うん。
  - ハブに挿したものを使える？たぶん無理。
  - 端末の消費電力が大きくて Tab5 をブラウンアウトさせる場合、ハブが救ってくれる？うーん。「救う」の定義による。
  - 複数のデバイス速度の混在がライブラリ側で非対応で、任意の機器の速度も当方からは分からない。
- DRM 付きファイルは不可。
- DSD と APE は処理が重すぎる。

## 潜在的な問題

- 保存した Wi-Fi ネットワークとリモートの証明書は、ボードの NVS、名前空間 `defeatist` にある。SD カード launcher の下では、ボード上の各ファームウェアが同じパーティションを共有する：他のアプリがそれらを読めてしまい（ここでは NVS は暗号化されていない）、NVS を消去するアプリはそれらも一緒に持っていく。設定はカードから戻るが、ネットワークと証明書は戻らない。

- 給電不足の USB-C + バッテリー装着 + 画面オンでの充電は、スピーカーのうなりに聞こえるが実はそうではない音を生むことがある。より良い USB ケーブル、より良いハブ、充電器への直結を。あなたは「アンペア不足」だ。
- ファイル選択が望みよりやや遅いのは、「親指の真下の最初の曲を選ぶ」のが求める挙動ではないから。
- AUX ケーブルは、周囲のあらゆるものを遮蔽できるとは限らない。電磁気学的な「スマホをもっと離せ」がここでも当てはまる。
