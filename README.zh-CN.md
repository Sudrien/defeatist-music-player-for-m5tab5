# Defeatist 音乐播放器 *for M5Tab5*

[English](README.md) · **简体中文** · [日本語](README.ja.md) · [Español](README.es.md)

大多数 M5Tab5 媒体播放器要求你先*转换*文件。这一个不用。

本项目的目标，是在不改动硬件的前提下榨干这台设备的潜力。不焊接，不加任何无法事后拆除的配件。凡是 ESP32-P4 v1.3 在不依赖秘技的情况下能合理处理的格式，都支持。

> 本译文为机器翻译，以英文版 [README.md](README.md) 为准。屏幕上的短标签请对照 [ABBREVIATIONS.zh-CN.md](ABBREVIATIONS.zh-CN.md)。

## M5Stack Tab5 并不是一台理想的音乐播放器。

- 你以为它有蓝牙。
  - 它只有低功耗蓝牙（BLE），也就是说使用经典蓝牙的老设备永远看不到它。
  - LE Audio / Auracast 需要不同的接线与配置文件。重刷 C6 或许能用，但那需要[专用设备](https://docs.m5stack.com/en/guide/restore_factory/m5tab5_c6_wifi)。
- 它有一个耳机口。
  - 接耳麦很好。接 AUX 线也行。理论上还能录音。
  - 但没有任何东西在监听线控按键。据说可以接出来，不过这又要（不算太特殊的）专用设备。
- 显示和触摸由同一颗芯片控制。你可以关掉背光省电，但没法把显示完全关掉。
- 还有显示驱动那一团乱。
  - 首发（2025.5.9）：独立的 ILI9881C 显示驱动 + GT911 触摸控制器
  - 2025.10.14：换成 ST7123 显示触摸一体（TDDI）驱动
  - 2026.4.28：驱动 IC 从 ST7123 改成 ST7121（我手上这台就是这款）

## 三种场景

1. 没有存储，但有 Wi-Fi（或以太网转接头）：可以收听网络电台。
2. 有存储，但没有音乐：可以录制 FLAC 文件以备回放。
3. 既有存储又有音乐：这就是你的音乐播放器——带不带耳机都行，支持 USB 音频类（UAC）转接头。

## 以下是我在 ESP-IDF ~~5.5.5~~ 6.1 上跑通的功能

- microSD 卡与 USB 闪存盘热插拔
  - 优先用 microSD 卡，耗电更少。
  - 不过只要 USB 指示为绿色，它也会自动挂载 USB；若不是绿色，到设置里重新打开 USB 供电。
- exFAT 支持
  - SDHC 与 SDXC 卡都测过（后者用了一周就挂了，但不是软件的锅）。SDUC 没测过。蓝光大小的音频文件能不能播？天知道。
- 拔插时在耳机与内置扬声器之间自动切换
  - 音量滑块旁的图标显示当前实际在响的输出——扬声器、耳机，或 USB 音频设备占用输出时显示 `UAC`。点按即可静音/取消静音。
- 支持（据我所知）所有 MP3 格式变体。这东西一层接一层地堆了无数后备库。Flac、ogg、wav 这些标准格式也都在。
- 封面显示：无论图片是嵌在文件里，还是以 cover.jpg / folder.jpg / front.jpg 放在专辑旁边。
- 电池状态，以文字显示在状态行末尾：`BATT 73%`、`CHRG 73%`、`CHARGED`、`NO BATT`。
- 状态行上的 Wi-Fi：绿色已连接，黄色连接中，灰色关闭。
- 音量控制
- 播放/暂停
- 回到曲首 / 上一曲（双击）
- 下一曲
- 息屏
- 拖动定位。上面列出的每种格式都支持。
- 播放顺序按钮循环切换 ONE / ALL / RPT / EAT / RND / RPT1——各自的含义，以及屏幕上其它所有短标签，见 [ABBREVIATIONS.zh-CN.md](ABBREVIATIONS.zh-CN.md)。
- 定位条上的音量波形。我觉得挺酷。
- USB 音频类（UAC）支持——那种“给 PS5 加蓝牙耳机”的转接头在这里也能用。仅限 USB-A 口。
- 暂停时切断功放供电。
- SDRAM 缓存。如果你发现换歌前 20 秒左右出现异常，请提 issue。
- ReplayGain 支持。第一次完整听完一首歌时，Defeatist 会陪你一起听——之后再播放时，它会在合理范围内把偏轻的歌调响、偏响的歌调轻。合理的依据是 [BS.1770](https://www.itu.int/rec/R-REC-BS.1770/en)。
  - 定位条上的波形来自同一次聆听。一首歌在被完整听过一遍之前，它的波形是纯灰色的。
  - 在这第一遍里跳转或拖动定位会取消它——下次再试。
  - 这份元数据存在隐藏的 `.songname.rgcache` 里。你无法关闭计算，但可以在设置里关闭音量调整。
- ARK 12 字体覆盖了相当一部分 Unicode，但并不完美。
- 启动时重新打开上次播放的歌曲。不是自动播放。
- 拔出媒介时 3 秒淡出。
- 可配置的交叉淡入淡出。
- 认真对待无缝播放（gapless）数据。
- 通过 <https://www.radio-browser.info> API 收听网络电台，或手动输入列表。这属于“得插着电”的领域。
  - 支持 MP3、AAC 和 Ogg 流，以及明文或 MPEG-TS 分段、内含 AAC 或 MP3 的 HLS（`.m3u8`）。暂不支持：加密或 fMP4 的 HLS，以及电台自己下发的 `.pls`/`.m3u` 链接。
- 阿拉伯语标题与电台名，按从右到左连写排布，靠右对齐。
- 睡眠定时（最长 2 小时，15 分钟一档）。
- 闲置关机：在无播放、无录音、无触摸时经过 15 分钟到 2 小时后关机——与睡眠定时相互独立。倒计时期间状态行上的 `IDLE` 为绿色，有事物阻止关机时为黄色；侧键可重新开机。
- 低电量保护：电池电压低于 6.3 V 持续 30 秒时，它会结束正在进行的录音并自行关机，以免电池被耗到亏电受损。尚未经过真实放电验证。
- 亮度控制。
- 网络时间协议（NTP，需已配置 Wi-Fi）。
- 电池供电的时钟在关机后仍保持时间，因此即便没有 Wi-Fi，录音文件也能正确命名；有网时 NTP 会校正。
- 强制门户（captive portal）Wi-Fi 配置（支持多个路由器）。
- 在 Wi-Fi 门户网页中手动输入网络电台。
- 收藏（Starred Favorites）。
- USB 以太网转接头：CDC-ECM（已测 Realtek RTL8152；RTL8153 走同一路径，未测）与 [ASIX AX88772](https://github.com/Sudrien/esp_usbh_asix) 移植，两者都已在板上确认可用。
- Cue 表单。
- m3u/m3u8——至少通过 MPD 可用。
- 对了，还有 [Music Player Daemon](https://mpd.readthedocs.io/en/stable/user.html) 支持——也就是说应该能用 Home Assistant 控制。
- 基于 HTTPS 的网页界面。
- 音频录制，既然硬件就在那儿，录成 FLAC。
  - 录制时带电平表。
- 音量下方的一行状态：USB 供电、MPD、HTTPS，以及睡眠定时剩余分钟。绿色表示开启。
- 哦天，我看了一眼 M5Launcher 的应用列表，赶紧把标题顺序修一下。
- 界面语言（English、简体中文、日本語、Español），在 设置齿轮 >> BUILD 标签页中选择。
- [bmorcelli/Launcher](https://github.com/bmorcelli/Launcher) 支持
  - 退回 Launcher
  - Wi-Fi 凭据导入

## 现有已发布代码做不到的

- 经典蓝牙转接头支持。
- 单文件断点续播。
- USB 集线器。
  - 它能不能看出你插了集线器？能。
  - 它能不能用插在集线器上的东西？多半不能。
  - 如果你的设备耗电大到会让 Tab5 掉电重启，集线器能不能救你？呃，看你怎么定义“救”。
  - 库不支持多种设备速率，而且我无法得知任意设备的速率。
- 带 DRM 的文件免谈。
- DSD 与 APE 需要的处理量太大。

## 潜在问题

- 保存的 Wi-Fi 网络和远程控制证书存放在板载 NVS 的 `defeatist` 命名空间里。在 SD 卡 launcher 之下，板上每个固件共用同一个分区：别的应用能读到它们（这里的 NVS 未加密），而会擦除 NVS 的应用会把它们一并带走。设置能从卡里恢复，但网络和证书不会。

- 用供电不足的 USB-C + 已装电池 + 开着屏幕充电，可能出现看似扬声器啸叫、实则不是的声音。换更好的 USB 线、更好的 Hub、或直连充电器。你这是“欠安培”了。
- 文件选择比我希望的要慢一点，因为“选中你拇指正下方的第一首歌”并不是你想要的结果。
- AUX 线未必能屏蔽掉你周围的一切干扰。电磁学上的“把手机拿远点”在这里同样适用。

- 本项目代码为 MIT。
- minimp3 为 CC0／公有领域。无署名义务；仍然就地引入（vendored），以便源码在树内可审计。
- esp_audio_codec 以 **预编译归档** 形式提供，采用 ESPRESSIF MIT 许可。免费，但授权仅限 Espressif 芯片使用。在此无妨；但若此代码被搬到别处则需留意。
- pngle 与 miniz 为 MIT。
- **TJpgDec 属 ChaN，采用其自有许可**，以 `espressif/esp_jpeg` 组件形式引入。宽松许可——个人和商业使用均免费，允许源码再分发——但必须保留版权声明，因此它会像字体的 OFL 一样随再分发一起附带。仅用作后备，用于硬件 JPEG 解码器无法分配内存的封面：P4 的解码器没有缩放器，一张 3000 px 的封面需要一整块 17 MB 的 PSRAM，而它拿不到。
- **Ark Pixel 字体为 SIL OFL-1.1，因此 `components/ark12` 同样是 OFL-1.1，而非 MIT。** 把字形 PNG 转成 C 数组，使这些文件成为 OFL 第 5 节下的“修改版本”，而第 5 节要求修改版本仍以 OFL 授权。这不成问题——OFL 明确允许与任意许可的软件打包，且仅字体文件受此约束——但 `components/ark12/LICENSE-OFL` 必须随任何再分发（含固件镜像）一起附带，且这些表格不得单独出售。Ark 未声明保留字体名（Reserved Font Name），因此衍生版本无需改名；它仍叫 `ark12`，只因它不是原始版本。
- **Arabixel Basic 为 CC BY 4.0**（ArabianDev，<https://arabiandev.itch.io/arabixel-basic-font>），因此 `components/arabixel` 的字体文件与生成的表格亦然；其整形（shaping）代码为 MIT。CC BY 要求署名、附许可链接并注明改动——该组件的 README 与表格头部已载明这些信息，再分发（含固件镜像）须随附 `components/arabixel/LICENSE.txt`。
- MurmurHash2 为公有领域。
